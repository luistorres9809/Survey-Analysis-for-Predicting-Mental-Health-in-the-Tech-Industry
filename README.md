# Predicting Mental Health Help-Seeking in the Tech Industry — ML + Survey Analysis

## Overview
Employee mental health is a critical factor in high-pressure environments. This project uses survey data from OSMI (Open Sourcing Mental Illness) to build a machine learning approach for understanding patterns and predicting help-seeking behavior / mental health-related outcomes in the tech industry.

## Goals
- Explore survey patterns related to workplace mental health
- Build predictive models using survey features
- Evaluate model performance with standard ML metrics

## Tech Stack
- Python
- Pandas / NumPy
- Scikit-learn
- Jupyter Notebook

## Methodology
1. Data cleaning (missing values, inconsistent categories)
2. Encoding categorical variables
3. Feature selection / engineering
4. Train/test split
5. Model training (baseline + improved model)
6. Evaluation (accuracy, precision, recall, F1)
